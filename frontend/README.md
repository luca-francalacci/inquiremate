# InquireMate Frontend

## Descrizione del progetto
Frontend di InquireMate realizzato in React.

## Installazione
### Prerequisites:
- node===18.17.1
- @mui/material===5.15.11

### Avvio
``` bash
npm install
```

Per far avviare il progetto, digitare sul terminale:
``` bash
npm start
```

Il progetto verrà avviato all'indirizzo: [http://localhost:3000](http://localhost:3000) nel tuo browser.

## Guida rapida
### Web Scraping
**ATTENZIONE!** è fondamentale avviare anche il backend del progetto.

Cliccare nel menù la voce Scraping.
- Nella casella di testo dove troverai scritto "Chiedimi qualcosa", digitare un qualcosa che si desidera cercare su internet.
- Selezionare un nuemro di risultati desiderati. Potrebbe dare un numero inferiore, rispetto a quello indicato.
- Cliccare Invia.
A questo punto il software inizierà a ricercare i siti web e si aprirà una schermata.

Adesso avrete la possibilità di scegliere quale sito e con quale profondità di sotto link scendere.

Cliccare dunque invio. A termine, le informazioni ricercate, verranno aggiunte al database.

### Query
Restituisce gli embedding che si trovano salvati sul database, più vicini a quello che è stato digitato.

### Home
Per tornare alla pagina iniziale, è necessario cliccare sul logotipo (sulla scritta InquireMate), situato nella barra del menù.
