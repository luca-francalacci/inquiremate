# Inquerimate

## Descrizione del progetto
La web app ha due obiettivi:
- effettuare lo scraping;
- realizzare embedding;
- restituzione degli embedding a seconda della query.

## Struttura del progetto
Il progetto si divide in due cartelle:
- backend: lato server;
- frontend: lato client.

## Istallazione
### Prerequisiti
Guardare le due sottocartelle: troverai un readme per entrambe.

### Clonazione del repository
Aprire un terminale sul pc e digitare il seguente codice per scaricare il progetto.
``` bash 
git clone https://github.com/luca-francalacci/InquireMate.git
```
